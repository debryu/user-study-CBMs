You can obtain the same experimental procedure employed in our studies by creating a new project on SoSci Survey (https://www.soscisurvey.de/) and importing the .xml files contained in this folder.

To ensure proper functioning, you will also need to import the database for contents of each project (under “Special Features -> Database for contents”) and ensure the images for the CUB projects are already imported (otherwise, import them under “Images and media files”)
